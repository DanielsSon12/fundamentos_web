Laboratório: Objects em JavaScript

10 atividades práticas para exercitar criação, manipulação, consulta e composição de objetos.

Orientações

Resolva as atividades utilizando os recursos de objetos indicados. O laboratório começa com operações básicas e evolui para objetos aninhados, métodos, arrays de objetos e composição de dados.

Sempre que possível, transforme suas soluções em funções reutilizáveis e teste os códigos com diferentes valores.

Objetivo: desenvolver segurança no uso de objetos antes de avançar para aplicações maiores e estruturas de dados mais complexas.

1. Criando e acessando um objeto — Básico

const aluno = {
  nome: "Mariana",
  idade: 21,
  curso: "Sistemas de Informação"
};

Exiba no console:
1. O nome do aluno.
2. A idade.
3. O curso.

Depois, altere a idade para 22.

Conceitos: notação de ponto e colchetes.
Desafio: acesse cada propriedade utilizando uma forma diferente.

2. Adicionando e removendo propriedades — Básico

const produto = {
  nome: "Notebook",
  preco: 3500,
  estoque: 10
};

Adicione a propriedade categoria com o valor "Informática".
Altere o estoque para 8.
Remova a propriedade estoque.
Exiba o objeto final.

Conceitos: atribuição de propriedades, delete.
Desafio: tente criar a propriedade desconto somente depois da criação do objeto.

3. Verificando propriedades — Básico

const usuario = {
  nome: "Carlos",
  email: "carlos@email.com",
  idade: 30
};

Verifique se o objeto possui as propriedades "email", "telefone" e "idade".
Mostre uma mensagem indicando quais propriedades existem.

Conceitos: Object.hasOwn(), in.
Desafio: compare o comportamento de Object.hasOwn(usuario, "email") com "email" in usuario.

4. Listando propriedades e valores — Básico

const carro = {
  marca: "Toyota",
  modelo: "Corolla",
  ano: 2024,
  cor: "preto"
};

Exiba:
1. Todas as propriedades do objeto.
2. Todos os valores.
3. Cada par propriedade/valor no formato:
marca: Toyota

Conceitos: Object.keys(), Object.values(), Object.entries().
Desafio: utilize Object.entries() para gerar as linhas automaticamente.

5. Calculando dados de um objeto — Intermediário

const produto = {
  nome: "Teclado",
  preco: 250,
  quantidade: 4
};

Crie uma propriedade total representando o valor total do estoque.
O cálculo deve ser preco × quantidade.

Resultado esperado:
total: 1000

Conceitos: acesso e criação de propriedades.
Desafio: crie uma função calcularTotal(objeto) que funcione para qualquer produto com preco e quantidade.

6. Trabalhando com objetos aninhados — Intermediário

const funcionario = {
  nome: "Ana",
  cargo: "Desenvolvedora",
  endereco: {
    cidade: "Nova Friburgo",
    estado: "RJ",
    cep: "28600-000"
  }
};

Exiba a cidade, o estado e o CEP do funcionário.
Depois, altere a cidade para "Rio de Janeiro".

Conceitos: objetos aninhados e acesso encadeado.
Desafio: utilize optional chaining (?) para acessar uma propriedade que pode não existir.

7. Criando métodos em objetos — Intermediário

const conta = {
  titular: "João",
  saldo: 1500
};

Adicione ao objeto um método depositar(valor) que aumente o saldo.
Adicione também um método consultarSaldo() que exiba o saldo atual.

Teste:
conta.depositar(500);
conta.consultarSaldo();

Conceitos: métodos de objetos, this.
Desafio: crie também um método sacar(valor) que impeça saques maiores que o saldo.

8. Trabalhando com arrays de objetos — Intermediário

const alunos = [
  { nome: "Ana", nota: 8.5 },
  { nome: "Bruno", nota: 6.0 },
  { nome: "Carlos", nota: 9.2 },
  { nome: "Daniel", nota: 7.0 }
];

Crie operações para:
1. Listar os nomes dos alunos.
2. Encontrar os alunos com nota maior ou igual a 7.
3. Encontrar o aluno com a maior nota.
4. Calcular a média da turma.

Conceitos: map(), filter(), find(), reduce().
Desafio: ordene os alunos pela nota, da maior para a menor.

9. Copiando e combinando objetos — Avançado

const dadosPessoais = {
  nome: "Marina",
  idade: 28
};

const dadosProfissionais = {
  cargo: "Analista",
  salario: 4500
};

Crie um novo objeto pessoa contendo todas as propriedades dos dois objetos.
Não altere os objetos originais.

Conceitos: Object.assign(), spread operator (...).
Desafio: crie uma terceira propriedade chamada resumo com uma frase gerada a partir dos dados.

10. Laboratório final — sistema de produtos — Avançado

const produtos = [
  { id: 1, nome: "Notebook", categoria: "Informática", preco: 3500, estoque: 4 },
  { id: 2, nome: "Mouse", categoria: "Informática", preco: 120, estoque: 15 },
  { id: 3, nome: "Cadeira", categoria: "Móveis", preco: 900, estoque: 6 },
  { id: 4, nome: "Teclado", categoria: "Informática", preco: 250, estoque: 10 }
];

Crie um programa que:
1. Liste os nomes dos produtos.
2. Calcule o valor total em estoque de cada produto (preco × estoque).
3. Calcule o valor total de todo o estoque.
4. Encontre o produto mais caro.
5. Liste somente os produtos da categoria "Informática".
6. Encontre o produto pelo id informado.
7. Crie um resumo contendo quantidade de produtos e valor total do estoque.

Conceitos: objetos, arrays de objetos, map(), filter(), find(), reduce(), Object.keys().
Desafio final: organize a solução em funções reutilizáveis e evite alterar diretamente os objetos originais.

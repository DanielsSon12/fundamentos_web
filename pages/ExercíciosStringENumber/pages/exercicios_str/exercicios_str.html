Lista de Exercícios — JavaScript String API

10 exercícios práticos com dificuldade progressiva

1. Padronização de nome

Considere o código abaixo:

const nome = "   joÃO da silVA   ";

Crie um programa que:

  1. Remova os espaços no início e no final da string.
  2. Converta o nome para letras minúsculas.
  3. Exiba o resultado no console.

Resultado esperado:

joão da silva
Conceitos: trim(), toLowerCase().

2. Verificação de domínio de e-mail

const email = "aluno@exemplo.com";

Escreva um programa que verifique se o e-mail pertence ao domínio @exemplo.com.

O programa deverá imprimir:

E-mail válido

ou:

E-mail inválido
Conceito principal: endsWith().

3. Contagem de caracteres

const frase = "JavaScript é muito interessante";

Crie um programa que mostre:

  1. A quantidade total de caracteres.
  2. A quantidade de caracteres desconsiderando os espaços.

Exemplo de saída:

Total: 32
Sem espaços: 28
Conceitos: length, replaceAll().

4. Busca de palavra

const mensagem = "Estou estudando JavaScript para desenvolver aplicações web.";

Verifique se a palavra JavaScript aparece na mensagem.

O programa deve exibir:

A mensagem contém JavaScript.

ou:

A mensagem não contém JavaScript.
Conceito principal: includes().

5. Extração de nome de usuário

const email = "carlos.silva@gmail.com";

Extraia somente o nome do usuário, ou seja, a parte que aparece antes do @.

Resultado esperado:

carlos.silva
Sugestão: utilize indexOf() e slice().

6. Substituição de informações

const mensagem = "Olá, João! Seja bem-vindo, João!";

Substitua todas as ocorrências de João por Maria.

Resultado esperado:

Olá, Maria! Seja bem-vindo, Maria!
Conceito principal: replaceAll().
Desafio extra: resolva também utilizando replace() com expressão regular.

7. Formatação de código de produto

const codigo = "abc123456";

Crie um programa que transforme o código para o seguinte formato:

ABC-123456

O programa deverá:

  1. Converter as letras para maiúsculas.
  2. Inserir um hífen depois das três primeiras letras.
Conceitos: toUpperCase(), slice().

8. Inversão de uma string

const palavra = "javascript";

Crie uma função chamada inverterString() que receba uma string e retorne os caracteres na ordem inversa.

Exemplo:

console.log(inverterString("javascript"));

Resultado esperado:

tpircsavaj
Restrição: não utilize um loop for para realizar a inversão.
Conceitos: split(), reverse(), join().

9. Análise de uma senha

const senha = "JavaScript123";

Crie uma função que verifique se a senha atende aos seguintes requisitos:

  • Possui pelo menos 8 caracteres.
  • Possui pelo menos uma letra maiúscula.
  • Possui pelo menos uma letra minúscula.
  • Possui pelo menos um número.

A função deverá retornar true caso todos os requisitos sejam atendidos ou false caso contrário.

Desafio: resolva utilizando principalmente operações sobre String.

10. Formatação de nome completo

const nome = "   maria   da   silva   ";

Crie uma função formatarNome() que:

  1. Remova espaços desnecessários no início e no final.
  2. Elimine espaços duplicados entre as palavras.
  3. Converta o nome para letras minúsculas.
  4. Coloque a primeira letra de cada palavra em maiúscula.

Resultado esperado:

Maria Da Silva
Sugestão: utilize trim(), split(), map(), toLowerCase(), toUpperCase(), slice() e join().

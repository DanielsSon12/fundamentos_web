Laboratório: Métodos Auxiliares de Arrays

20 atividades práticas para exercitar manipulação, consulta, transformação, filtragem, ordenação e redução de arrays em JavaScript.

Orientações

Resolva as atividades utilizando os métodos de arrays indicados. Evite escrever soluções equivalentes com estruturas de repetição quando o objetivo for praticar um método específico.

Sempre que possível, crie funções reutilizáveis e teste cada solução com mais de um conjunto de dados.

Nível: as atividades começam com operações básicas e avançam para métodos de alta ordem e combinações de métodos.

1. Adicionando e removendo elementos — Básico

const frutas = ["maçã", "banana", "laranja"];

Faça as seguintes operações:
1. Adicione "uva" ao final.
2. Adicione "abacaxi" ao início.
3. Remova o último elemento.
4. Remova o primeiro elemento.

Ao final, exiba o array resultante.

Método(s): push(), pop(), unshift(), shift().

2. Criando uma cópia de parte do array — Básico

const numeros = [10, 20, 30, 40, 50, 60];

Crie um novo array contendo somente os elementos das posições 2 até 4, sem alterar o array original.

Resultado esperado:
[30, 40, 50]

Método(s): slice().

3. Substituindo elementos em um array — Básico

const cores = ["azul", "verde", "amarelo", "vermelho"];

Substitua "verde" e "amarelo" por "roxo" e "laranja", respectivamente.
Depois, insira "preto" na posição 1 sem remover os elementos existentes.

Método(s): splice().
Desafio: resolva as duas operações sem criar um segundo array.

4. Unindo arrays — Básico

const frontEnd = ["HTML", "CSS", "JavaScript"];
const backEnd = ["Node.js", "Python", "Java"];

Crie um novo array chamado tecnologias contendo os elementos dos dois arrays.
Os arrays originais não devem ser modificados.

Método(s): concat().

5. Transformando array em texto — Básico

const palavras = ["JavaScript", "é", "uma", "linguagem", "poderosa"];

Transforme o array em uma frase, utilizando um espaço como separador.

Resultado esperado:
JavaScript é uma linguagem poderosa

Método(s): join().

6. Verificando a existência de um elemento — Básico

const linguagens = ["JavaScript", "Python", "Java", "C#"];

Crie uma função temLinguagem(nome) que retorne true caso a linguagem exista no array e false caso contrário.
Teste com "Python" e "Ruby".

Método(s): includes().
Desafio: faça uma versão que ignore diferenças entre maiúsculas e minúsculas.

7. Localizando elementos — Básico

const nomes = ["Ana", "Bruno", "Carlos", "Ana", "Daniel"];

Descubra:
1. A posição da primeira ocorrência de "Ana".
2. A posição da última ocorrência de "Ana".
3. A posição de "Marcos".

Método(s): indexOf(), lastIndexOf().

8. Percorrendo um array — Básico

const produtos = ["Notebook", "Mouse", "Teclado", "Monitor"];

Utilize um método de array para exibir cada produto no console acompanhado de seu índice.

Exemplo:
0 - Notebook
1 - Mouse
2 - Teclado
3 - Monitor

Método(s): forEach().

9. Criando uma lista de preços com desconto — Intermediário

const precos = [100, 250, 80, 320, 150];

Crie um novo array em que todos os preços tenham desconto de 10%.

Resultado esperado:
[90, 225, 72, 288, 135]

O array original deve permanecer inalterado.

Método(s): map().

10. Filtrando números pares — Intermediário

const numeros = [3, 8, 11, 14, 21, 26, 30, 35];

Crie um novo array contendo somente os números pares.

Resultado esperado:
[8, 14, 26, 30]

Método(s): filter().

11. Encontrando um objeto — Intermediário

const alunos = [
  { nome: "Ana", nota: 8.5 },
  { nome: "Bruno", nota: 6.0 },
  { nome: "Carlos", nota: 9.2 },
  { nome: "Daniel", nota: 7.5 }
];

Encontre o primeiro aluno cuja nota seja maior ou igual a 9.
Exiba o objeto encontrado.

Método(s): find().

12. Encontrando a posição de um objeto — Intermediário

const produtos = [
  { id: 101, nome: "Notebook" },
  { id: 205, nome: "Mouse" },
  { id: 310, nome: "Teclado" },
  { id: 450, nome: "Monitor" }
];

Crie uma função buscarIndice(id) que retorne a posição do produto com o ID informado.
Se o produto não existir, o resultado deve ser -1.

Método(s): findIndex().

13. Verificando se algum elemento atende a uma condição — Intermediário

const notas = [5.5, 6.0, 7.2, 8.0, 9.5];

Verifique se existe pelo menos uma nota maior ou igual a 9.
Depois, altere o programa para verificar se existe alguma nota abaixo de 6.

Método(s): some().

14. Verificando se todos atendem a uma condição — Intermediário

const idades = [22, 31, 19, 27, 40];

Verifique se todas as pessoas possuem 18 anos ou mais.
Depois, teste com:
const idades2 = [22, 17, 19, 27, 40];

Método(s): every().

15. Calculando o total de uma compra — Intermediário

const precos = [29.90, 49.90, 15.50, 100.00];

Calcule o valor total da compra.

Resultado esperado:
195.30

Método(s): reduce().
Desafio: crie uma versão que receba um array de objetos com nome e preco.

16. Ordenando números corretamente — Intermediário

const numeros = [100, 8, 25, 3, 45, 12];

Crie:
1. Um array com os números em ordem crescente.
2. Um array com os números em ordem decrescente.

Resultado crescente:
[3, 8, 12, 25, 45, 100]

Método(s): sort().
Atenção: explique por que sort() sem função de comparação não produz a ordenação numérica esperada em todos os casos.

17. Invertendo e reorganizando dados — Intermediário

const fila = ["Ana", "Bruno", "Carlos", "Daniel"];

Crie uma versão invertida da fila sem modificar o array original.

Resultado esperado:
["Daniel", "Carlos", "Bruno", "Ana"]

Método(s): slice(), reverse().
Desafio: explique por que utilizar apenas reverse() pode alterar o array original.

18. Trabalhando com arrays aninhados — Avançado

const categorias = [
  ["HTML", "CSS"],
  ["JavaScript", "TypeScript"],
  ["Node.js", "Express"]
];

Transforme o array em um único array contendo todas as tecnologias.

Resultado esperado:
["HTML", "CSS", "JavaScript", "TypeScript", "Node.js", "Express"]

Método(s): flat().
Desafio: teste o comportamento com três níveis de aninhamento.

19. Transformando e expandindo dados — Avançado

const turmas = [
  { nome: "Turma A", alunos: ["Ana", "Bruno"] },
  { nome: "Turma B", alunos: ["Carlos", "Daniel", "Eva"] }
];

Crie um array contendo todos os nomes dos alunos, independentemente da turma.

Resultado esperado:
["Ana", "Bruno", "Carlos", "Daniel", "Eva"]

Método(s): flatMap().
Desafio: crie um array contendo objetos no formato { nome, turma }.

20. Pipeline de processamento de dados — Avançado

const vendas = [
  { produto: "Notebook", categoria: "Informática", valor: 3500, quantidade: 2 },
  { produto: "Mouse", categoria: "Informática", valor: 120, quantidade: 5 },
  { produto: "Cadeira", categoria: "Móveis", valor: 900, quantidade: 3 },
  { produto: "Teclado", categoria: "Informática", valor: 250, quantidade: 4 },
  { produto: "Mesa", categoria: "Móveis", valor: 1200, quantidade: 1 }
];

Crie um programa que:
1. Considere apenas as vendas da categoria "Informática".
2. Calcule o valor total de cada venda (valor × quantidade).
3. Calcule o faturamento total dessas vendas.
4. Identifique o produto que gerou o maior faturamento individual.
5. Crie uma lista contendo somente os nomes dos produtos.

Método(s): filter(), map(), reduce(), find(), sort() e/ou outros métodos.
Desafio final: tente resolver utilizando uma sequência de operações encadeadas (method chaining), evitando loops explícitos.
